# design.slashbro.top

Slashbro's searchable showcase of 74 brand design systems, generated from the
open-source [`awesome-design-md`](https://github.com/VoltAgent/awesome-design-md)
collection.

## Deployment

- Host: Cloudflare Pages
- Production branch: `main`
- Custom domain: `design.slashbro.top`
- Build command: none
- Output directory: repository root

The site is fully static. Open `index.html` locally or serve this directory with
any static HTTP server.
